How to save jobs (main feature)

  1. Install ApplyPulse Saver Chrome extension (Load unpacked).
  2. Login in the extension (same account).
  3. Open any job on LinkedIn or Indeed.
  4. Click extension → Save this job (title/company auto-filled from page).
  5. It appears here under Applications. Update status anytime.
